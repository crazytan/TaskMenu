TaskMenu Support

Last updated: May 11, 2026

Need help with TaskMenu? This page explains the best ways to get support, report a problem, or find project information.

Get help

  • Open a support request or bug report on GitHub Issues.
  • Check existing reports on the TaskMenu issue tracker.
  • Review setup and release notes in the project README.

Common topics

  • Signing in: TaskMenu uses Google OAuth so you can access your own task lists.
  • Disconnecting: Open Settings in TaskMenu and choose Disconnect Google Account to remove locally stored OAuth tokens.
  • Quitting: Right-click the menu bar icon and choose Quit TaskMenu, or use the Quit TaskMenu button in the app.
  • Privacy: Read the Privacy Policy for details about local token storage, task data, and diagnostics.
